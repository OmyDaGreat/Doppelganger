= Doppelganger
:toc: left
:toclevels: 3
:source-highlighter: rouge
:icons: font

*Type-safe SVG DSL for Kotlin Compose Multiplatform*

image:https://img.shields.io/maven-central/v/xyz.malefic/doppelganger[Maven Central,link=https://central.sonatype.com/artifact/xyz.malefic/doppelganger]
image:https://img.shields.io/github/license/OmyDaGreat/Doppelganger[License,link=LICENSE]

Doppelganger is a comprehensive SVG library for Kotlin that provides a type-safe DSL for creating and rendering SVG graphics across all Compose Multiplatform targets. Write SVG markup using intuitive Kotlin code and render it seamlessly on JVM, Android, iOS, JavaScript, and WebAssembly.

== Features

* 🎨 **Type-Safe DSL** - Intuitive Kotlin-first API with full IDE support
* 🌐 **True Multiplatform** - Native support for JVM, Android, iOS, JS, and Wasm
* 🧩 **Compose Integration** - Works seamlessly with Compose UI across all platforms
* 🌐 **Kobweb Support** - First-class integration for Kobweb web applications
* ⚡ **KSP Plugin** - Compile-time SVG resource generation with zero runtime overhead
* 📐 **Comprehensive Elements** - All SVG elements: shapes, paths, text, gradients, masks, and more
* 🎭 **Advanced Features** - Gradients, clipping paths, masks, and transformations
* 🔧 **Path DSL** - Fluent API for complex path construction

== Quick Start

=== Installation

Add Doppelganger to your `build.gradle.kts`:

[source,kotlin]
----
kotlin {
    sourceSets {
        commonMain {
            dependencies {
                implementation("xyz.malefic:doppelganger:1.0.1")
            }
        }
    }
}
----

=== Basic Example

Create SVG graphics using the type-safe DSL:

[source,kotlin]
----
@Composable
fun MyCircle() {
    SvgImage(modifier = Modifier.size(100.dp)) {
        width(100)
        height(100)
        viewBox(0, 0, 100, 100)
        
        circle {
            cx(50)
            cy(50)
            r(40)
            fill(Color.Blue)
            stroke(Color.Black)
            strokeWidth(2)
        }
    }
}
----

== Core API

=== SvgImage - Inline SVG Creation

The primary way to create and render SVG graphics:

[source,kotlin]
----
@Composable
fun GradientExample() {
    SvgImage(modifier = Modifier.size(200.dp)) {
        width(200)
        height(200)
        
        defs {
            linearGradient {
                id("myGradient")
                x1("0%")
                y1("0%")
                x2("100%")
                y2("100%")
                
                stop {
                    offset("0%")
                    stopColor("purple")
                }
                stop {
                    offset("100%")
                    stopColor("pink")
                }
            }
        }
        
        rect {
            width(200)
            height(200)
            fill("url(#myGradient)")
        }
    }
}
----

=== SvgContent - Reusable SVG Elements

Create and reuse SVG elements:

[source,kotlin]
----
val mySvg = svg {
    width(100)
    height(100)
    circle {
        cx(50)
        cy(50)
        r(40)
        fill(Color.Red)
    }
}

@Composable
fun MyComponent() {
    SvgContent(
        svgElement = mySvg,
        modifier = Modifier.size(100.dp)
    )
}
----

== Kobweb Integration

For https://github.com/varabyte/kobweb[Kobweb] web applications, Doppelganger provides specialized APIs that work with Kobweb's `Modifier` system.

=== Installation for Kobweb

[source,kotlin]
----
kotlin {
    js {
        browser()
    }
    
    sourceSets {
        val jsMain by getting {
            dependencies {
                implementation("xyz.malefic:doppelganger:1.0.1")
                // Kobweb dependencies
                implementation("com.varabyte.kobweb:kobweb-core")
                implementation("com.varabyte.kobweb:kobweb-silk")
            }
        }
    }
}

// Optional: Add KSP for resource generation
dependencies {
    add("kspCommonMainMetadata", "xyz.malefic:doppelganger-ksp:1.0.1")
}

// Configure KSP to generate into Kobweb public resources
ksp {
    arg("doppelganger.output.package", "public.images.icons")
}
----

**Generate Icon Files:**

[source,kotlin]
----
// In commonMain:
@SvgResource
fun homeIcon() = svg {
    width(24)
    height(24)
    path {
        d("M10 20v-6h4v6h5v-8h3L12 3 2 12h3v8z")
        fill("currentColor")
    }
}

// After KSP runs, use in Kobweb:
@Page
@Composable
fun HomePage() {
    Image(
        src = "/images/icons/homeIcon.svg",
        modifier = Modifier.size(24.px)
    )
}

== SVG Elements

Doppelganger supports the complete SVG specification:

=== Basic Shapes

[source,kotlin]
----
svg {
    // Rectangle
    rect {
        x(10); y(10)
        width(80); height(80)
        fill("coral")
        rx(5) // rounded corners
    }
    
    // Circle
    circle {
        cx(50); cy(50); r(40)
        fill("steelblue")
    }
    
    // Ellipse
    ellipse {
        cx(50); cy(50)
        rx(40); ry(30)
        fill("purple")
    }
    
    // Line
    line {
        x1(0); y1(0)
        x2(100); y2(100)
        stroke("black")
        strokeWidth(2)
    }
    
    // Polyline
    polyline {
        points("0,0 50,25 50,75 100,100")
        fill("none")
        stroke("red")
        strokeWidth(2)
    }
    
    // Polygon
    polygon {
        points("50,0 100,100 0,100")
        fill("green")
    }
}
----

=== Paths

Doppelganger includes a powerful Path DSL:

[source,kotlin]
----
svg {
    path {
        // String-based path data
        d("M 10,30 A 20,20 0,0,1 50,30")
        fill("none")
        stroke("blue")
        strokeWidth(2)
    }
    
    // Or use the DSL builder
    path {
        d {
            moveTo(10, 10)
            lineTo(50, 50)
            curveTo(70, 10, 90, 30, 100, 10)
            closePath()
        }
        fill("orange")
    }
}
----

=== Text

[source,kotlin]
----
svg {
    text {

        textAnchor("middle")

        fontFamily("Arial")

        tspan {
            content("First line")
            x(10)
            dy(0)

        tspan {
            content("Second line")

}
----

=== Gradients

[source,kotlin]
----
svg {
    defs {
        // Linear gradient
        linearGradient {
            id("grad1")
            x1("0%"); y1("0%")
            x2("100%"); y2("0%")
            
            stop { offset("0%"); stopColor("yellow") }
            stop { offset("100%"); stopColor("red") }
        }
        
        // Radial gradient
        radialGradient {
            id("grad2")
            cx("50%"); cy("50%"); r("50%")
            
            stop { offset("0%"); stopColor("white") }
            stop { offset("100%"); stopColor("blue") }
        }
    }
    
    rect {
        fill("url(#grad1)")
        width(200); height(100)
    }
    
    circle {
        fill("url(#grad2)")
        cx(100); cy(100); r(80)
    }
}
----

== KSP Plugin: Compile-Time SVG Generation

Doppelganger includes a powerful Kotlin Symbol Processing (KSP) plugin that generates SVG resource files from your DSL code at compile time.

=== Setup

Add the Doppelganger plugin and KSP to your project:

[source,kotlin]
----
plugins {
    id("com.google.devtools.ksp") version "2.3.0"
    id("xyz.malefic.doppelganger") version "1.0.1"
}

dependencies {
    implementation("xyz.malefic:doppelganger:1.0.1")
    add("kspCommonMainMetadata", "xyz.malefic:doppelganger-ksp:1.0.1")
}

// Optional: Configure output location (auto-detects by default)
doppelganger {
    outputPackage.set("public.images")  // Type-safe!
    outputSubdir.set("icons")
    autoDetect.set(true)  // Default: true
}
----

**Smart Defaults** - The plugin automatically detects your project type:

* **Kobweb projects**: `public/images` (accessible via `/images/icon.svg`)
* **Multiplatform with commonMain**: `files/drawable` (Compose Resources)
* **JS-only projects**: `public/images` (web resources)

=== Usage

Annotate your SVG DSL functions with `@SvgResource`:

[source,kotlin]
----
@SvgResource
fun homeIcon() = svg {
    width(24)
    height(24)
    viewBox(0, 0, 24, 24)
    
    path {
        d("M10 20v-6h4v6h5v-8h3L12 3 2 12h3v8z")
        fill("currentColor")
    }
}

@SvgResource(resourceName = "custom_name")
fun myLogo() = svg {
    // Custom filename: custom_name.svg
    width(200)
    height(100)
    // ... your SVG content
}
----

Generate the SVG files:

[source,bash]
----
./gradlew :library:generateSvgResources
----

=== Configuration

The Doppelganger Gradle plugin provides type-safe configuration with smart defaults:

[source,kotlin]
----
doppelganger {
    // Output package path (maps to directory structure)
    outputPackage.set("public.images.icons")
    
    // Optional subdirectory within the package
    outputSubdir.set("")
    
    // Enable/disable automatic project detection
    autoDetect.set(true)  // Default: true
}
----

==== Automatic Detection

With `autoDetect = true` (default), the plugin automatically configures the output location:

.Detection Logic
|===
|Project Type |Default Output |Access Path

|Kobweb (has kobweb plugin)
|`public.images`
|`/images/icon.svg`

|Multiplatform with commonMain
|`files/drawable`
|`Res.readBytes("files/drawable/icon.svg")`

|JS-only or other
|`public.images`
|`/images/icon.svg`
|===

==== Manual Configuration

**For Kobweb Web Resources:**
[source,kotlin]
----
doppelganger {
    outputPackage.set("public.images.icons")
}

// Generated files accessible via:
Image(src = "/images/icons/homeIcon.svg")
----

**For Compose Multiplatform Resources:**
[source,kotlin]
----
doppelganger {
    outputPackage.set("files")
    outputSubdir.set("svg")
}

// Access via Compose Resources API
val svgBytes = Res.readBytes("files/svg/homeIcon.svg")
----

**Custom Web Resource Path:**
[source,kotlin]
----
doppelganger {
    outputPackage.set("public.assets.graphics")
}

// Files at: src/jsMain/resources/public/assets/graphics/
// URL: /assets/graphics/homeIcon.svg
----

=== How It Works

The KSP plugin architecture consists of two modules:

1. **library** module - Contains the `@SvgResource` annotation and core DSL (multiplatform)
2. **processor** module - KSP processor that detects annotated functions (JVM-only)

The workflow is:

1. **Compilation**: KSP scans your code for `@SvgResource` annotations
2. **Task Execution**: The `generateSvgResources` Gradle task executes the annotated DSL functions
3. **File Generation**: SVG files are written to `src/commonMain/composeResources/files/`
4. **Resource Access**: Use generated files via Compose Resources API

=== Benefits

* ✅ **Type Safety** - SVG structure validated at compile time
* ✅ **Zero Runtime Overhead** - Pre-generated static resources
* ✅ **Version Control** - Generated SVG files can be committed and reviewed
* ✅ **Reusability** - Use functions directly or as generated files
* ✅ **IDE Support** - Full autocomplete and refactoring

=== Troubleshooting

**Files not generating?**

* Verify the annotation is imported correctly
* Ensure function returns `Svg` type
* Run KSP: `./gradlew :library:kspCommonMainKotlinMetadata`
* Check output: `library/src/commonMain/composeResources/files/`

**Access generated files:**

[source,kotlin]
----
// Using Compose Resources API
val svgBytes = Res.readBytes("files/homeIcon.svg")
val svgString = svgBytes.decodeToString()
----

== Advanced Topics

=== Custom Attributes

Add any SVG attribute using the generic setter:

[source,kotlin]
----
svg {
    circle {
        cx(50); cy(50); r(40)
        set("data-id", "my-circle")
        set("aria-label", "Decorative circle")
    }
}
----

=== Color Support

Use Compose Color or string-based colors:

[source,kotlin]
----
svg {
    rect {
        fill(Color.Red)  // Compose Color
        stroke("#FF0000") // Hex string
        fill("rgb(255, 0, 0)") // RGB
        fill("hsl(0, 100%, 50%)") // HSL
    }
}
----

=== Rendering to String

Convert SVG to string representation:

[source,kotlin]
----
val mySvg = svg {
    circle {
        cx(50); cy(50); r(40)
        fill(Color.Blue)
    }
}

val svgString = mySvg.render()
// Output: <svg><circle cx="50" cy="50" r="40" fill="#0000FF"/></svg>
----
